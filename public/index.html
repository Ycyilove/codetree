批量导入文件

      
    

    

      

        每行一个路径，相对于启动目录。也可以直接粘贴本工具输出的
        ====== path ====== 段落。空行和以 # 开头的行会被忽略，重复路径自动去重。
        

        快捷键：Ctrl/Cmd + I 打开，Esc 取消输入框激活，再按一次关闭；Ctrl/Cmd + Enter 导入并复制。
      

      
      

    

    

      
      
      
    

  






  

    

      
操作指引

      
    

    

      
路径输入框

      
    
        
  • 
          Enter
          激活路径输入框（主界面搜索框 / 批量导入文本域），光标聚焦并全选内容。
        
    • 
        
  • 
          Esc
          取消输入框激活。主界面：若有搜索结果，第一次 Esc 清空搜索并收起列表（保持激活），再按一次取消激活。批量导入：第一次 Esc 取消激活，再按一次关闭弹层。
        
    • 
      


      
搜索结果导航（主界面）

      
    
        
  • 
          ↑↓
          在搜索结果列表中上下移动高亮项。
        
    • 
        
  • 
          空格
          选中 / 取消选中当前高亮的文件（支持多选），文件会出现在右侧清单并打勾。
        
    • 
      


      
全局快捷键

      
    
        
  • 
          Ctrl/Cmd/
          打开 / 关闭本操作指引。
        
    • 
        
  • 
          CtrlICmdI
          打开批量导入弹层。
        
    • 
        
  • 
          CtrlEnterCmdEnter
          在批量导入弹层中导入并复制。
