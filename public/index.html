操作指引

          
        

        

          
输入框激活

          
    
            
  • 
              Enter
              
                焦点不在任何输入框时，激活搜索框并全选内容——这是切换工作目录后
                最常用的入口，用于快速定位文件。
              
            
    • 
            
  • 
              /
              
                非输入状态下按
                斜杠键，激活路径输入框，用于输入绝对路径
                切换整个项目根目录。
              
            
    • 
            
  • 
              CtrlKCmdK
              
                与
                /
                等效，激活路径输入框。跨平台更一致，不依赖键盘布局。
              
            
    • 
            
  • 
              Esc
              
                取消输入框激活。若搜索框有内容，第一次 Esc
                先清空搜索，再按一次取消激活。 弹窗打开时，Esc 关闭弹窗。
              
            
    • 
            
  • 
              Enter在路径框
              
                焦点已在路径框时，读取该目录。焦点在树中某一行时，切换该行的选中 / 排除。
              
            
    • 
          


          
键盘区域切换

          
    
            
  • 
              ←→
              
                ← 把键盘归属切到左侧 目录文件列表；
                → 切到右侧 输出区。
                当前归属区域左侧会显示一条蓝色内边线。 光标停在目录行上时，← →
                不切换区域（留给 P 用于折叠判断）。
              
            
    • 
            
  • 
              TabShift+Tab
              
                循环切换顶部三个标签：全部 → 目录结构 → 文件内容。
                Shift + Tab 反向切换。
              
            
    • 
            
  • 
              点击
               用鼠标点击任一区域，键盘归属同步切换。 
            
    • 
            
  • 
              默认
              载入项目后默认归属 目录文件列表。
            
    • 
          


          
方向键与翻页

          
    
            
  • 
              ↑↓
              
                归属
                目录列表
                时：在可见项之间上下移动光标（搜索状态下在结果里移动）。 归属
                输出区 时：原生上下滚动。
              
            
    • 
            
  • 
              PgUpPgDn
              
                归属列表时按页移动光标；归属输出区时按页滚动。
              
            
    • 
            
  • 
              HomeEnd
              
                归属列表时跳到首 / 末项；归属输出区时滚到顶部 / 底部。
              
            
    • 
            
  • 
              空格
              
                归属列表时，切换当前光标的选中状态。 文件 → 加入 /
                移出内容清单； 目录 → 从目录结构中排除 / 恢复。
                被排除的目录仍可被选中，光标留在原地；它的所有子目录与文件都不再进入选中范围，
                直到重新勾选。
              
            
    • 
          


          
折叠 / 展开

          
    
            
  • 
              P
              
                归属列表且光标在目录行时，折叠该目录；已折叠时展开。不区分大小写。
              
            
    • 
            
  • 
              点击三角
              点击目录行左侧的三角箭头，同样折叠 / 展开。
            
    • 
          


          
搜索

          
    
            
  • 
              Enter
              
                激活搜索框开始输入。在搜索框里按 ↑ ↓ PgUp PgDn
                会直接把键盘归属交给结果列表，并定位到第一个结果。
              
            
    • 
            
  • 
              Esc
              清空搜索并返回完整树。
            
    • 
          


          
复制

          
    
            
  • 
              CtrlCCmdC
              
                归属
                目录列表 且光标在某一行时：复制该行相对根目录的路径。
                归属 输出区 时：复制输出区全部内容。
                焦点在输入框内时不拦截，保留原生复制。
              
            
    • 
            
  • 
              CtrlEnterCmdEnter
              
                与点「复制」按钮等效。导入弹窗打开时，为导入。
              
            
    • 
          


          
标签与文件清单

          
    
            
  • 
              全部/目录结构/文件内容
              
                三个标签分别输出：目录结构 + 文件内容、仅目录结构、仅文件内容。
              
            
    • 
            
  • 
              文件内容
              
                切到该标签时，输出区顶部会列出所有已选文件的相对路径，便于核对。
              
            
    • 
          


          
全局快捷键

          
    
            
  • 
              CtrlICmdI
              打开 批量导入文件 弹窗。
            
    • 
            
  • 
              Ctrl/Cmd/
              打开 / 关闭本操作指引。
            
    • 
          


          
读取方式

          
    
            
  • 
              拖入
              把项目文件夹拖到窗口里，直接读取（本地，不需服务器）。
            
    • 
            
  • 
              选择
              点「选择文件夹」，用系统对话框选取（本地，不需服务器）。
            
    • 
            
  • 
              路径
              
                按 / 或 Ctrl/Cmd + K 激活路径框，
                输入绝对路径回车。需要 Node 服务器（npm start
                后访问 http://localhost:3000）。支持任意位置，
                ~ 展开为用户主目录。
